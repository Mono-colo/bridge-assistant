# 数桥识别助手

这是一个 Windows 本地桌面工具：从当前运行的应用窗口采集 Hashi（数桥/搭桥）题面，自动定位棋盘、识别岛屿和数字、求出满足规则的桥，然后用鼠标把答案输入回原应用。识别基于屏幕像素，不读取网页 DOM，也不限定浏览器。

## 支持的规则

- 桥只能水平或垂直连接同行、同列中相邻的岛。
- 两岛之间最多两座桥。
- 桥不能交叉，也不能穿过其他岛。
- 每个岛相连的桥数等于岛上的数字。
- 全部岛必须属于同一个连通区域。

## 运行

已安装 Python 3.10+ 时，双击 `run_bridge.bat`，或执行：

```powershell
python -m pip install -r requirements.txt
python -m bridge_assistant
```

## 使用

1. 在浏览器、模拟器或其他应用中打开未作答的题面。
2. 点击“选择窗口”，从当前可见窗口列表中选择目标。列表按具体窗口显示进程名、PID 和标题，因此同一浏览器进程的多个窗口可以分别选择。
3. 点击“采集画面”。程序只会还原并激活目标窗口、截取完整可见客户区并显示原图，不在采集阶段定位、识别或求解。选择一次窗口后可以多次采集更新画面。
4. 点击“识别画面”。程序此时才会自动定位唯一可信的棋盘、裁剪并识别岛屿和候选连接；定位不以题目存在可行解为条件。若定位失败或窗口中同时有多个题面，使用“框选题面”指定棋盘后再点击“识别画面”。
5. 检查预览和右侧数字列表，再点击“求解”。橙色条目置信度较低，可双击预览中的岛或列表条目修改数字；双击空白处可补岛。
6. 确认蓝色桥的预览正确，保持默认的“靠近端点点击（必要时中点）”，或明确选择目标应用需要的兼容方式，再点击“执行到应用”。

操作方式：

- **靠近端点点击（必要时中点，默认）**：优先在岛屿轮廓外、连接线内部单击。点击位置按“岛中心 + 朝另一岛的单位方向 ×（岛半径 + 自适应安全间距）”计算，并校验不会落入其他岛或贴近其他候选线。若连接过短或两端附近都没有满足条件的安全点击位置，则自动改用该线段的精确中点，不中止整批输入。水平、垂直连接采用同一规则。`cn.puzzle-bridges.com` 使用此方式。
- **拖拽岛到岛（兼容）**：仅供明确要求从一个岛拖到另一个岛的应用使用。
- **点击桥中点（兼容）**：仅供明确要求点击线段中部的应用使用。
- **依次点击两岛（兼容）**：仅供要求先点一个岛、再点另一个岛的应用使用。

单桥点击一次，双桥会在同一位置点击两次；请先确认目标应用按 `0 → 1 → 2` 循环增加桥数。若目标应用必须分别用左键/右键设置单桥和双桥，当前版本不能直接执行。窗口在采集后仅平移时，程序会在执行前重新读取客户区并更新绝对点击坐标；窗口大小、DPI、页面缩放或内容改变后必须重新采集。执行前会激活绑定的窗口并重新截图校验岛屿位置，每次输入后还会检查对应桥走廊是否出现视觉变化。若未确认到变化，同一个桥操作最多额外重试 50 次（连同首次操作最多尝试 51 次），之后仍无变化才会停止。视觉确认不能识别当前是 `0`、`1` 还是 `2` 座桥，误判重试可能使目标应用按 `0 → 1 → 2 → 0` 循环；执行期间可按 `Esc` 中止，`pyautogui` 的屏幕左上角保护也保持启用。

“打开图片”用于载入离线画面；载入后仍需明确点击“识别画面”，再按需修正、求解和保存预览。图片没有屏幕绝对坐标，因此不能直接执行鼠标操作；要操作应用必须使用“选择窗口”加“采集画面”，或使用备用的“框选题面”。

## 识别范围

当前识别器面向常见的数桥界面。一个岛必须同时满足两个条件：外部是闭合的圆或近圆轮廓，圆内是合法的 `1` 到 `8` 单个数字；裸数字、空圆以及圆内的 `0`、`9` 或字母不会作为岛返回。点击“识别画面”后，程序会在采集到的原始物理像素中分块扫描候选，按相近半径、水平/垂直对齐和空间连通性定位题面；裁剪后重新完整识别，只接受唯一通过结构校验的棋盘，既不调用求解器，也不要求识别结果已经可解。工具栏里的圆形数字不会直接并入题面。小尺寸题面会标准化到可读的岛尺寸，再融合多个圆内裁剪尺度识别数字；结果按行聚类、行内从左到右稳定编号，以降低缩放、模糊、JPEG 压缩和亚像素抖动造成的漏检、误读或编号交换。它可以适配不同应用、分辨率、缩放和多显示器坐标，但不保证识别方形岛、手写题、强透视照片或装饰非常复杂的皮肤。对这类画面可使用“框选题面”或在预览中手工修正。

窗口采集获取的是屏幕上实际显示的客户区：最小化窗口会先还原，普通遮挡会通过激活窗口消除，但置顶浮窗、受保护内容、独占全屏、UAC 安全桌面和高权限目标可能无法可靠截图或输入。目标客户区必须完整位于虚拟桌面内。

程序不会绕过目标应用的权限或输入限制。操作方式必须与目标应用本身的鼠标协议一致。

## 测试

```powershell
python -m pip install pytest
python -m pytest -q
```

测试覆盖窗口枚举和客户区坐标、自动棋盘定位、4K 小棋盘、圆形控件干扰、多个题面消歧、求解规则、近端点安全点击位置、屏幕坐标映射、逐次视觉确认和执行前场景校验。识别回归还逐岛校验原图、`65%` 缩小图、强模糊图和低质量 JPEG，并验证只有“闭合圆环 + 合法数字”的组合会被识别为岛。

Windows 桌面端到端验收会连续 5 次启动一个带圆形工具栏干扰、只接受桥走廊单击的独立测试应用。每轮从窗口枚举绑定目标，先采集完整客户区，再依次执行定位识别和求解，最后通过真实屏幕截图、窗口激活和系统鼠标点击将它解完。验收同时覆盖水平单桥与垂直双桥，并核对每次按下/抬起坐标和前台窗口：

```powershell
python scripts/run_desktop_e2e.py
```
